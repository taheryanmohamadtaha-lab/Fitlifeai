# فیت‌لایف (FitLife AI)

اپلیکیشن اندرویدی فارسی برای کاهش وزن اصولی، تغذیه ایرانی و پیگیری وزن، با توجه به ایمنی ستون فقرات.
همه اطلاعات فقط روی گوشی شما ذخیره می‌شود و برنامه بدون اینترنت کار می‌کند.

## امکانات نسخه فعلی (مرحله ۱ و ۲)
- پروفایل و محاسبه BMI / BMR / TDEE (فرمول Mifflin-St Jeor) و هدف‌های روزانه قابل ویرایش
- داشبورد: کالری، پروتئین، کربوهیدرات، چربی، فیبر، آب، وزن و نمودار
- رژیم غذایی: ثبت وعده‌ها، بانک غذایی ایرانی، افزودن غذای جدید، برنامه ۷ روزه و فهرست خرید
- پیگیری وزن و دور شکم، مراحل هدف، میانگین هفتگی
- حالت شب (مشکی) و روز، پشتیبانی کامل راست‌به‌چپ
- حذف کامل اطلاعات توسط کاربر
- پایش درد کمر و پا (۰ تا ۱۰)، انتشار، بی‌حسی، گزگز، ضعف، نمودار روند و ارتباط فعالیت‌ها با درد
- هشدار فوری اورژانس برای ضعف پا، بی‌حسی ناحیه زینی و اختلال ادرار/مدفوع
- یادآوری‌های قابل تنظیم (وعده‌ها، آب، وزن، علائم، تغییر وضعیت بدن، گزارش هفتگی)
- گزارش‌ها (۷، ۳۰ و ۹۰ روز) و خروجی Excel (CSV)
- عکس‌های پیشرفت در حافظه خصوصی برنامه
- پشتیبان‌گیری و بازیابی

مراحل بعدی: بانک تمرینات تأییدشده، مربی هوشمند، ثبت فعالیت روزانه.

> این برنامه جایگزین پزشک یا فیزیوتراپیست نیست و هیچ تمرین درمانی پیشنهاد نمی‌دهد.

## ساخت APK با GitHub (بدون نیاز به برنامه‌نویسی)
1. در github.com وارد حساب خود شوید.
2. ریپوی پروژه را باز کنید.
3. همه فایل‌های این پروژه را در ریپو آپلود کنید (Add file ← Upload files).
4. به تب **Actions** بروید و workflow با نام **Build Android APK** را انتخاب کنید.
5. روی **Run workflow** بزنید.
6. وضعیت ساخت را ببینید (دایره زرد = در حال ساخت، تیک سبز = موفق).
7. پس از موفقیت، وارد همان اجرا شوید و در پایین صفحه بخش **Artifacts** فایل `FitLife-release-apk` را دانلود کنید و از حالت فشرده خارج کنید.
8. فایل `app-release.apk` را به گوشی منتقل کنید و نصب کنید (اگر خواست، «نصب از منابع ناشناس» را برای مرورگر/مدیر فایل مجاز کنید).

## ساختار
- `lib/` کد برنامه (Flutter)
- `assets/icon/` آیکون برنامه
- `.github/workflows/android-build.yml` ساخت خودکار APK
- پوشه `android/` در زمان ساخت به‌صورت خودکار تولید می‌شود.
